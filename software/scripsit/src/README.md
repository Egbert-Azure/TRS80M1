# scripsit/src — original artefacts

Files as they came off the disk. **Byte-exact, unmodified.** Nothing here is meant to render on
GitHub; that is the point of it.

Everything derived from these lives one level up, and says so in its own header. See
[`../README.md`](../README.md) for the index.

| File | What it is |
|---|---|
| `SCRIPSIT.TXT` | **The SCRIPSIT/SP manual, October 1988.** An original Scripsit document, 10650 bytes: TRS-80 German 7-bit encoding (`5B 5C 5D 7B 7C 7D 7E` = Ä Ö Ü ä ö ü ß), Scripsit paragraph and page marks, 154 bytes of `E5` sector fill at the end, and **seventeen `7F` bytes** — the hatched square produced by `@p`, each followed by two hex digits. Readable versions: [`../scripsit-sp-anleitung.md`](../scripsit-sp-anleitung.md) (DE), [`../scripsit-sp-manual-en.md`](../scripsit-sp-manual-en.md) (EN). |

## Provenance

`SCRIPSIT/TXT` comes from **`esnd-05.dmk`** (author's statement). It is not on `esnd-04.dmk`,
whose directory was checked and holds no manual. The copy here was supplied directly and has not
been re-extracted from `esnd-05.dmk`, so it is byte-verified against nothing but itself.

This is the only surviving contemporaneous document about the modification; the 1988 Club-80
article (SONDERINFO 27.5) is lost.
